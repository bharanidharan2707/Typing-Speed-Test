# Typing Speed Test

## About
A typing practice website that measures typing speed and accuracy within a 60-second test.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Display a typing passage
- Run a 60-second countdown timer
- Calculate words per minute (WPM)
- Calculate typing accuracy
- Highlight correct and incorrect characters
- Display final test results
- Restart the test

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser, or use Live Server.
3. Click **Start Test** and type the displayed passage.
4. View your speed and accuracy.

## Learning Outcomes
Learn JavaScript timers, string comparison, event handling, calculations, and DOM manipulation.
